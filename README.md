# TypeScript Basics - Homework 05

This project sets up a TypeScript development environment with compiler configurations and source maps enabled.

## Features
- **TypeScript**: Typed functions and DOM interactions.
- **Source Maps**: Enabled in `tsconfig.json` for easier browser debugging.
- **Dev Server**: Integrated with `@web/dev-server`.
